# 🐍 Python Learning Journey: Build First, Study Along the Way

I'm learning Python by building things, not by finishing courses first. Small practice code goes up most days

**Where this is heading:** data science and AI/ML. Python is the foundation, so every project here is also practice for that.

---

## How I learn

1. Pick a small project slightly beyond what I currently know.
2. Build it. Look things up *when I get stuck*, not before.
3. Push it. Write down what I actually learned.
4. Come back later and refactor old projects with better techniques.

No copy-pasted tutorial code is presented as my own work. If I followed a tutorial, the project README says so.
